27 PDFs linked on the current site were not available as current local copies in the archive. Their URLs were checked during the migration, but their bytes were not downloaded in the build environment.

Download these while your existing domain still points to Wix. Save each PDF at the exact path below, relative to the extracted project folder. Create subfolders where needed. Do not change DNS or cancel Wix first.

Automatic route

npm run import:wix
npm run build
npm run check:launch

The importer checks PDF headers, does not overwrite valid existing files, and reports failures. The launch check also requires completed content review and noindex removal; it is expected to fail before those steps.
