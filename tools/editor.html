Content editor

Edit one record, download its JSON file, and move it into the corresponding content/ folder. Nothing is sent to a server or published.

The menu reflects the last build. Import the current JSON file to edit changes made since then. Saving here downloads a file; it does not overwrite your source automatically.

Inspect or edit the complete JSON record

Advanced fields are preserved when using the form. After editing JSON below, choose “Apply JSON changes” before downloading.
